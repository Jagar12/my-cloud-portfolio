
# AWS Cloud Projects

This repository contains several projects I've worked on while learning more about AWS and building hands-on experience with cloud services.

Each project focuses on a different use case, from image recognition and text-to-speech to chatbots and AI-assisted scheduling. My goal was to get more comfortable connecting AWS services, configuring permissions, writing code, and troubleshooting issues along the way.

---

#### Projects

**[Image Recognition Using Amazon Rekognition and S3](https://github.com/Jagar12/my-cloud-portfolio/tree/main/Rekognition-Project)**

A Python-based project that uses Amazon Rekognition to identify objects in images stored in S3. The script returns labels with confidence scores and displays detected objects with bounding boxes where available.

**[Text Narrator Using Amazon Polly and AWS Lambda](https://github.com/Jagar12/my-cloud-portfolio/tree/main/Polly-Text-Narrator)**

A text-to-speech project that uses a Node.js Lambda function to send text to Amazon Polly and save the generated audio files in S3.

**[TaskTide - AI-Powered Daily Task Scheduler](https://github.com/Jagar12/my-cloud-portfolio/tree/main/PartyRock-Project)**

A scheduling application built with PartyRock, powered by Amazon Bedrock. Users can enter tasks and available time to generate a daily schedule, along with a motivational quote, image, and chatbot for schedule adjustments.

[Try TaskTide on PartyRock](https://partyrock.aws/u/juliagarcia/FgansJz-v/TaskTide)

**[Language Translation Bot Using Amazon Lex](https://github.com/Jagar12/my-cloud-portfolio/tree/main/Language%20Translation%20Bot)**

A chatbot that collects text and a target language through Amazon Lex, then uses a Python Lambda function and Amazon Translate to return a translation.

Each project has its own README with more information about how I built it, the services involved, and what I learned.

- AWS CLI

- Node.js

#### What I've Been Learning

These projects have helped me practice working with AWS services in different combinations, especially when it comes to connecting applications with managed services.

I've spent time configuring IAM permissions, building and testing Lambda functions, using Python to interact with AWS, and troubleshooting issues when something didn't work as expected.

I've also started exploring generative AI tools through PartyRock and learned how changing a prompt can affect the application it creates.
